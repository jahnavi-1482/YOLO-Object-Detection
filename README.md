# YOLO Object Detection

## Project Overview
A web application that detects objects in uploaded images using YOLO
and displays the detected objects with bounding boxes and confidence scores.

## Technologies
- Python
- Flask
- Ultralytics YOLO
- Pillow
- HTML
- CSS

## Features
- Upload images
- Detect objects automatically
- Display bounding boxes
- Show object names and confidence scores

## Run Locally

Install dependencies:

    pip install -r requirements.txt

Start the application:

    python app.py

Open http://127.0.0.1:5000 in your browser.

## Deployment
The application is configured for deployment using Render.
